[구현 요약]

라벨 정규화: data.json의 다양한 라벨(+, x, cross)을 내부 표준인 Cross와 X로 통일하여 비교 로직의 일관성을 확보함.

MAC 연산: $O(N^2)$의 시간 복잡도를 가지는 중첩 반복문을 사용하여 패턴과 필터의 유사도를 계산함.

동점 처리: 부동소수점 연산 특성상 발생하는 미세한 오차를 해결하기 위해 1e-9 (Epsilon) 기준을 도입하여 판정의 신뢰도를 높임.

[결과 리포트: 실패 원인 분석]

질문: 만약 FAIL이 발생했다면 왜 그랬을까요? 혹은 0 FAIL이라면 무엇 때문일까요?

데이터/스키마 문제: data.json 내의 패턴 크기와 필터 크기가 매칭되지 않는 경우 (예: 5x5 패턴인데 3x3 필터 적용 시) 로직에서 예외 처리를 통해 FAIL로 분류함.

수치 비교 문제: 단순 == 비교를 사용했을 경우, 0.1+0.2=0.3과 같은 부동소수점 이슈로 인해 UNDECIDED가 뜰 수 있으나, 본 프로젝트에서는 abs(diff) < 1e-9 정책을 사용하여 이를 방지함.

[성능 분석: O(N2) 근거]

이론적 근거: N×N 크기의 행렬에서 모든 원소를 한 번씩 곱하고 더해야 하므로, 총 연산 횟수는 N2에 비례함.

실제 데이터 반영:
* 3×3=9회 연산
25×25=625회 연산
입력 크기 N이 8배 커지면 연산량은 약 64배 증가하며, 실제 측정된 ms 시간 역시 이와 유사한 곡선을 그리며 증가함을 확인 가능함.
